## v0.1.0-linepods - 2026-09-22

- 推出 Linepods：一款在 AI Passport 上运行、用于随时回顾微信读书划线的
  口袋应用。
- 新增首次使用欢迎页，用户主动开始配置前不启动 Wi-Fi。
- 新增本地 SoftAP 配网，可填写 2.4 GHz Wi-Fi 与微信读书 API Key，
  并在页面中提供明确的 API Key 获取路径。
- 新增划线同步、设备端持久缓存、离线卡片浏览和分页详情页。
- 新增更友好的配置、同步、成功与失败状态，并对完整界面和动态
  内容执行中文字形覆盖检查。
- 新增电量、时间指示，以及适配可穿戴设备的有界空闲和低功耗行为。
