# Changelog

## Unreleased

No unreleased changes.

## v0.1.0-linepods - 2026-09-22

- Introduced Linepods, an AI Passport application for reviewing Weixin Read
  highlights from a pocket-sized device.
- Added a first-run welcome screen that stays offline until the user chooses to
  begin setup.
- Added local SoftAP provisioning for a 2.4 GHz Wi-Fi network and a Weixin Read
  API Key, including clear in-app retrieval guidance.
- Added highlight synchronization, durable on-device caching, offline card
  browsing, and a paginated detail view.
- Added friendly setup, synchronization, success, and failure states, with
  Chinese font coverage checks for the complete interface and dynamic content.
- Added battery and time indicators plus bounded idle and low-power behavior for
  the wearable form factor.
